# Code of Conduct

This project adopts the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/) as its Code of Conduct.

In short: be kind, be respectful, assume good faith, and help keep this a welcoming place for everyone, regardless of background or experience.

## Reporting

If you experience or witness unacceptable behavior, please report it privately to the maintainers at [support@chialab.it](mailto:support@chialab.it).
All reports will be handled with discretion, and the maintainers will act as described in the Contributor Covenant's enforcement guidelines.
